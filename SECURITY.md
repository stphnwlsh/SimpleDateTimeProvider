# Security policy

## Supported versions

Fixes are made on `main` and go out in the next release. Only the latest release is supported, because one person can only keep so many plates spinning.

## Reporting a vulnerability

Please don't report security problems in a public issue. Announcing the hole before it's patched helps nobody except the people looking for holes.

Report it privately instead: open the [Security tab](https://github.com/stphnwlsh/SimpleDateTimeProvider/security) and choose **Report a vulnerability**. Include what's affected, how to reproduce it and the impact you expect.

You'll get a reply within 7 days. Once it's confirmed, a fix goes out as soon as possible, and you'll be credited in the advisory unless you'd rather not be.
